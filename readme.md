# 🌐 Personal Website — Zamzam Firdaus

> Website pribadi sederhana yang dibuat sebagai media untuk memperkenalkan diri, menampilkan project, serta menyediakan halaman kontak.

## 👋 Tentang Proyek

**Personal Website Zamzam Firdaus** merupakan website pribadi yang dikembangkan sebagai bagian dari proses pembelajaran **HTML dasar dan pengembangan website**.

Website ini menjadi tempat untuk memperkenalkan profil, menampilkan beberapa project yang pernah dan sedang dikerjakan, serta menyediakan form yang dapat digunakan pengunjung untuk menghubungi saya.

Website awalnya dibuat menggunakan **HTML dasar tanpa CSS**, kemudian dikembangkan dengan menambahkan stylesheet untuk memberikan tampilan yang lebih modern, interaktif, dan responsif.

---

## ✨ Fitur Website

Website terdiri dari beberapa halaman utama:

### 🏠 Home

Halaman utama yang berisi:

- Perkenalan singkat
- Foto profil
- Deskripsi diri
- Informasi mengenai hal yang sedang dipelajari
- Navigasi ke halaman lainnya

### 👤 About

Halaman yang berisi informasi lebih lengkap mengenai profil, meliputi:

- Profil singkat
- Data diri
- Hobi
- Riwayat pendidikan

### 💻 Projects

Halaman yang menampilkan beberapa project yang pernah atau sedang saya kerjakan:

#### 1. Zamzam Hidden Spot (ZHS)

Platform yang bertujuan untuk membantu pengguna menemukan **hidden gem wisata lokal** sekaligus membantu mempromosikan potensi wisata yang belum banyak terekspos.

#### 2. Kreswara Studio

Project game yang mengangkat hubungan antara **tradisi budaya dan dunia modern**. Cerita berpusat pada Kreswara Radyana, seorang pemuda berusia 19 tahun yang merupakan pewaris tradisi keluarga dalang dan memiliki impian menjadi programmer.

#### 3. JB Garage

Platform **Trust-Based Vehicle Marketplace** yang berfokus pada transaksi kendaraan bekas dengan memanfaatkan teknologi verifikasi, escrow, dan kecerdasan buatan untuk membantu mengurangi risiko penipuan.

### 📩 Contact

Halaman kontak yang menyediakan form untuk mengirim pesan.

Form mencakup:

- Nama lengkap
- Email
- Nomor telepon
- Jenis kelamin
- Tanggal lahir
- Topik pesan
- Jenis pesan
- Isi pesan
- Opsi pengiriman salinan pesan
- Tombol kirim dan reset

> **Catatan:** Form masih bersifat frontend dan belum terhubung dengan server atau database.

## 🚀 Cara Menjalankan

Karena website ini merupakan website frontend sederhana, Anda tidak memerlukan server khusus untuk menjalankannya.

### 1. Clone repository

```bash
git clone https://github.com/USERNAME/personal-website.git
```

### 2. Masuk ke folder project

```bash
cd personal-website
```

### 3. Jalankan website

Buka file:

```text
HOME.HTML
```

menggunakan browser seperti:

- Google Chrome
- Microsoft Edge
- Mozilla Firefox

### 4. Pastikan file CSS terhubung

Setiap halaman HTML harus memiliki:

```html
<link rel="stylesheet" href="style.css" />
```
